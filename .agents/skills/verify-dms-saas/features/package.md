# Package

What a project installs: the module and the interface packages as their manifests declare them.

## Sub-features

- `the-manifests-declare-what-the-docs-install`: the module implements the interface, ships its build, frontend and skill, and depends on the interface through a workspace range.

## How to get to it (user POV)

- `pnpm add @antelopejs/dms-saas`; the manifests under `packages/`.

## Driving it with dms-control

```bash
dms-control journey "$RUN" package
```

## Gotchas

- The journey reads the manifests of the checkout; it does not pack tarballs.
